三、权限、用户与压缩

1. 权限速查

权限字符串例如 -rwxr-x--- 可以拆成：文件类型 + 所有者 + 用户组 + 其他人。

数字权限记法：r = 4、w = 2、x = 1。例如 7 = 4+2+1，5 = 4+1。

目录的 x 不是“执行程序”，而是允许进入和访问其中的条目；目录通常需要 r+x 才能正常列出并访问内容。修改权限时，优先使用明确的 u/g/o，少用没有范围限制的递归命令。

2. 用户和身份

2. 磁盘和空间

“磁盘满了”时，先用 df -h 找到满的挂载点，再用 du 逐级定位大目录；不要直接删除不认识的系统目录。

磁盘分区、格式化、挂载属于高风险操作。执行 mount、umount、mkfs、fdisk 之前，先用 lsblk -f 确认设备名、文件系统和挂载点。

六、Ubuntu 根目录 / 下的文件夹是干什么的

先抓住一句：配置在 /etc，用户数据在 /home，程序和库分散在 /usr、/opt，日志和运行状态在 /var，设备在 /dev。

目录 作用 常见内容 / 备注
/ 根目录 所有文件和目录的起点
/bin 基础用户命令 新版 Ubuntu 通常链接到 /usr/bin
/boot 启动文件 内核、initramfs、GRUB；不要随便删除
/dev 设备文件 磁盘、串口、终端，如 /dev/sda、/dev/ttyUSB0
/etc 系统和软件配置 SSH、网络、systemd、用户等配置
/home 普通用户家目录 个人文件和用户配置通常在这里
/lib 系统共享库和内核模块 新版 Ubuntu 通常链接到 /usr/lib
/media 自动挂载的移动设备 U 盘、移动硬盘常在这里
/mnt 临时挂载点 手动挂载磁盘时常用
/opt 可选的第三方软件 手工安装、独立目录的软件常放这里
/proc 进程和内核的虚拟文件系统 运行时信息，不是普通磁盘文件
/root root 用户的家目录 不是根目录 /
/run 本次启动以来的运行时数据 PID、socket、锁文件等
/sbin 系统管理命令 新版 Ubuntu 通常链接到 /usr/sbin
/srv 服务对外提供的数据 Web、FTP 等服务可按约定放数据
/sys 内核设备和硬件信息 sysfs 虚拟文件系统
/tmp 临时文件 可能被系统定期清理，不放重要数据
/usr 大部分用户空间程序 /usr/bin 命令、/usr/lib 库、/usr/share 资源
/usr/local 管理员手工安装的软件 不属于系统包管理器的本地程序和库
/usr/share 与架构无关的共享资源 文档、man 手册、图标、locale 等
/var 经常变化的数据 日志、缓存、队列、数据库、包信息
/var/cache 可重新生成的缓存 apt 缓存和其它软件缓存
/var/lib 软件的持久化状态数据 dpkg、systemd、数据库等运行数据

现代 Ubuntu 使用 merged-/usr 布局：/bin、/sbin、/lib 往往是指向 /usr/bin、/usr/sbin、/usr/lib 的符号链接。看到这些目录“重复”是正常的，不要为了整理目录而删除或替换它们。

九、安全提醒：这些命令执行前多看一眼

命令 风险点
rm -rf 递归强制删除，没有回收站
sudo 以管理员身份修改系统
chmod -R 递归修改权限，可能影响系统或服务
chown -R 递归修改属主，目标写错会影响整个目录树
dd 可以直接覆盖磁盘或分区，参数错误会造成数据丢失
mkfs 格式化文件系统，会破坏目标分区数据
kill -9 强制杀进程，程序没有机会清理现场

执行高风险命令前，至少确认三件事：当前路径、目标对象、是否有备份。
